# ✈️ SkyFare AI — Flight Fare Prediction

A Machine Learning web application that predicts airline ticket prices based on travel details such as source, destination, airline, and number of stops.

The model is trained on historical flight data and deployed using **Flask**, allowing users to get instant fare predictions through a simple web interface.
